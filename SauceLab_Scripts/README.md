This repository contains a subset of the `project` workspace for Sauce demo test scripts.

Included packages:
- sauceDemo.generic
- sauceElements.pom
- sauceScripts.Test

Included folder:
- test-output (report files)

How to push to GitHub:
1. cd into this directory
2. git init
3. git add .
4. git commit -m "Initial import of Sauce demo scripts"
5. git remote add origin https://github.com/Shri27-Scripts/SauceLab_Scripts.git
6. git branch -M main
7. git push -u origin main

Note: You must run the git commands locally; this environment cannot authenticate to push to GitHub.
